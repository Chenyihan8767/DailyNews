# DailyNews

个人使用的 Android 英文新闻阅读器。Kotlin、Jetpack Compose、Material 3；暖黑 / 米白 / 苔绿主题，原生无衬线排版。

## 当前功能

- 今日：重点文章卡片、小图列表、分类、搜索、文章收藏。
- 订阅：预置 BBC、Guardian、Al Jazeera、CNA 候选 RSS；支持 HTTPS RSS / Atom 添加、启停、移除与逐源错误提示。
- 阅读：网页正文提取、原文跳转、阅读位置、离线正文；点词与已识别短语、段落翻译、摘要、词句分析。
- 点词可选：快速浮卡、底部面板、组合模式（默认）。
- 笔记：保存单词 / 短语 / 原句 / 段落，保留来源与语境，可返回文章。
- DeepSeek：可配置 HTTPS 地址、模型、API Key；连接测试；密钥由 Android Keystore 加密。
- AI处理：打开触发、收藏触发、每日自动精选三种入口；每日默认5篇；本地持久队列，阅读任务优先；可设置时间和后台仅Wi-Fi。
- 缓存：按正文哈希、接口、模型、处理版本缓存；分段处理检查ID、译文覆盖和原文引文；分块结果可以复用。
- 首次启动有明确标为「原创教学样文 / 非实时新闻」的离线演示，未配置API也能试读。

## 打开和构建

首次上传 GitHub、源码文件说明、Debug / Release APK 构建步骤见 [上传 GitHub 与构建 APK](docs/github-and-apk.md)。

用 Android Studio 打开本目录，同步 Gradle，然后运行 `app`。需要 JDK 17或21、Android SDK Platform 35、Build Tools 35.0.0。

```sh
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest :app:lintDebug
```

APK 在 `app/build/outputs/apk/debug/app-debug.apk`。最低 Android 8.0（API 26）。

本次工作区的构建环境位于被忽略的 `.tooling/` 内。使用以下脚本会优先使用它；其他电脑可直接使用 Android Studio 或自行配置 JDK / SDK：

```sh
./scripts/build.sh
./scripts/build.sh :app:testDebugUnitTest :app:lintDebug
```

## 第一次使用

1. 先打开教学样文，点击 `weigh` 或 `hold interest rates steady`，体验浮卡、详情与收藏。
2. 在「设置 → DeepSeek」保存自己的 API Key；默认地址 `https://api.deepseek.com`，默认模型 `deepseek-flash`，均可修改。
3. 点击「测试连接」。它会发起一次真实 API 调用。
   「DeepSeek」中还可设置单次最大输出 tokens、每块正文字符数、请求超时和输出超限自动拆分。默认最大输出为384K（393216 tokens），可按接口能力修改。升级会把旧默认 deepseek-chat / 7000 更新为新默认，其他自定义值保留。以接入接口实际支持的参数上限为准，正文字符数不是上下文tokens数。
4. 回到今日，点击刷新；订阅页会显示每个源的更新结果。
5. 阅读文章，或收藏 / 点击「准备精读」。未配置Key的队列在保存配置后继续；默认后台需要Wi-Fi。

不要把 API Key 放进代码、Git、截图或日志。自用版直接从手机请求配置的接口；正文和选中的词句会发给该接口。笔记、阅读记录和缓存保存在App私有目录；系统备份已关闭，卸载会删除本地数据。

## 实现范围和边界

- RSS通常只提供摘要，正文通过Jsoup提取可访问的网页内容；不绕过登录、付费墙、验证码或网站限制。提取不足时保留摘要和原文入口。
- 预置源的连通性、RSS格式、地区访问和正文提取成功率依原网站而变。各源独立失败，不会阻塞其他源。可在订阅页调整。
- 每日精选目前按四类轮选当日最新的报道，排除已标识的评论和直播；不是由AI判断全球重要性。关键词分类与重复URL过滤是第一版实现，尚无事件级聚合。
- 正文是下载时的阅读快照，不会自动追踪原网站更正。原文链接始终保留。
- AI译文和分析可能有误。校验能发现缺段、编号错位、截断和不存在的引文，不能证明事实或翻译语义100%正确。
- 后台时间由Android WorkManager调度，受省电、网络与系统限制，无法保证整点执行。强行停止应用后需再次打开才可恢复。
- 点击首页独立的「精读列表」入口可查看任务；等待、处理中、失败和就绪的文章均可打开阅读原文，列表内「准备今日精选」用于添加任务。
- 处理失败会展示原因，保留原文和成功分块，可手动重试。仅确认达到AI输出长度上限时，自动将分块拆小（最多3层）；其他错误不自动重复付费调用。重新打开失败文章会保留错误，点击「重试AI处理」才会重新处理。
- 笔记和缓存可离线使用；尚无语音、间隔复习、账号、云同步、导入导出和多来源事件对照。

## 代码结构

```text
app/src/main/java/com/dailynews/reader/
  data/        Room、设置与密钥、RSS、正文提取、DeepSeek与结果校验
  work/        每日任务、带优先级的持久预处理队列
  ui/          今日、订阅、阅读、笔记、设置与主题
app/src/test/  RSS/Atom、正文提取、分块与AI输出校验测试
```

视觉参考 [PixelPlayerOSS](https://github.com/PixelPlayerHQ/PixelPlayerOSS) 的 Material 3 思路；本项目未复制其源代码、图片或品牌资源。

## 本次阅读体验更新

- Android adaptive icon 支持 Pixel 启动器的圆形、圆角和 Android 13 主题图标。
- 点击阅读页标题或「翻译标题」生成中文标题，本地缓存可复用。
- 收藏文章、词语和段落有反馈；浮卡和面板显示收藏完成状态。
- 笔记卡片可打开详情，保存语境、释义、段落译文及词句分析快照。旧笔记优先从本地文章和词义缓存恢复分析。
- 主题与地区独立筛选；地区由标题关键词及订阅默认地区推断，不能保证每篇准确，亚太筛选包含亚洲和大洋洲。
- 预置27个英文订阅源，新增BBC地区/科技/健康、Guardian中国/台湾/澳洲/科学/环境/体育、HKFP、DW、France24、Global Voices、Japan Times等。候选新增地址的检查记录见 `docs/feed-verification.json`；404候选未加入。
- 数据库v1→v2使用增量迁移，保留文章、收藏、笔记和设置；新闻源目录仅在版本升级时补充，不会每次启动重新启用或添加已删除订阅。

## 筛选与收藏详情

- 首页仅保留一行「全部 / 主题 / 地区」，主题、地区通过弹窗选择并可组合；筛选中移除与不限重复的「综合」「全球」。
- 首页「精读列表」「文章收藏」分别打开独立页面，返回文章后保留所在列表；它们不再属于主题筛选。
- 句子收藏保存对应的原句、句子译文及结构分析，所在完整段落和段落译文可展开查看。段落收藏只展示一次完整译文，句子分析不重复翻译。
- 旧句子笔记按原文范围识别，译文根据段落ID和原句匹配，避免将整段译文当作一句的译文。阅读页词句面板可分别收藏单句或整段。
